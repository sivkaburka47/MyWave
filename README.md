# 📖 О программе
Приложение для мониторинга вашего самочувствия в течение дня с возможностью просмотра детализированной статистики за выбранные периоды.

## 👨‍💻 iOS Deployment Target: 17.5 

## 💻 Технический стек
- Swift
- UIKit
- MVVM
  
- SnapKit
